# Tanzania sources and scope

Reference check date: 10 November 2026.

| Source | What it supports |
| --- | --- |
| [Tanzania Insurance Regulatory Authority guidelines](https://www.tira.go.tz/publications/guidelines) | The regulator's current publications, including insurance product guidance and premium levy guidance. This repository does not reproduce a tariff or infer a customer charge from a publication title. |
| [Howden Tanzania motor insurance](https://www.howdengroup.com/tz-en/cover/motor-insurance) | Tanzania motor cover categories, reference to TIRA rating practice and the existence of additional cover terms. It does not supply a universal percentage for this template. |
| [BimaSokoni comprehensive quotation form](https://www.bimasokoni.co.tz/QuickQuote/QuickQuoteStartJourney?id=23) | A Tanzania quotation workflow that requests vehicle value for comprehensive cover, together with other underwriting information. The form is not a tariff schedule. |

For a live record, the insurer's actual quotation and the applicable rating schedule must establish the sum insured, rate, minimum and any adjustments. The script checks the arithmetic of those supplied inputs. It does not certify regulatory compliance or provide an insurance quotation.

No customer records or insurer premium rates are preloaded. There are no invented claim outcomes, client testimonials or project performance figures. Software tests use labelled numerical inputs to check calculation behaviour.

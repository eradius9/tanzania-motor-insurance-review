# Comprehensive motor record review

## Check the quotation

Confirm the insurer, quotation reference, cover type, period and vehicle use. Make sure the record describes the same vehicle as the source documents. Resolve a missing or conflicting reference before updating the register.

## Check the insured value and premium basis

Read the sum insured and the percentage rate separately. Confirm the applicable minimum base premium and any special rating terms. Recalculate the base premium only where the quotation uses the structure supported by this template.

Identify whether a premium figure is the base amount or an inclusive total. Read VAT, levies, fees, extensions and discounts from the actual quotation. A matching base calculation does not prove that a final payable total is correct.

## Prepare the follow-up

For each question, record the review reference, the source value, the reason it needs attention and the document or confirmation required. Keep missing facts blank. Record confirmed corrections with their source and date.

Before contacting a client about renewal, check whether a renewed term or another quotation already exists. For claims work, use the actual policy wording and claims process. This template does not assess claims.

## Share the result

Provide the reviewed register, the list of unresolved questions and a short handover note. Share client information only through the agreed channel. This public repository contains the blank template and review method only.
